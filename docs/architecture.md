# 简历工坊：技术架构

## 目标

在 Windows / macOS 本机提供一个浏览器式简历工作台，完成资料导入、结构化确认、岗位匹配、OCR 校对、项目材料整理、转行学习规划、事实约束改写、模板预览和 PDF/Word 导出。

## 数据流

```text
旧简历/图片/手填资料
        ↓
本地解析与 OCR
        ↓
结构化人才档案 ← 用户逐项确认
        ↓
职位描述（JD 文本 / 多张截图 → 逐张 OCR → AI 校对，可撤销）
        ↓
所选 AI 服务的要求拆解与证据匹配
        ↓
可选：文件夹材料 → 分批事实提取 → 类型识别/用户纠正 → 带证据案例草稿 → 用户确认
可选：跨行业差距 → 技能与前置关系拆解 → 实时课程发现 → 直达页校验 → 语义复核 → 本地缓存/用户反馈
        ↓
岗位草稿 → 用户直接编辑 / AI 局部调整 / 可选动态追问
        ↓
投递前检查（证据、可解释性、可读性）
        ↓
同源 HTML 预览与 PDF + 独立稳定 Word 导出
```

## 模块边界

- `app/main.py`：HTTP 路由、本地安全边界和静态资源。
- `app/demo_package.py`：在内存中生成两条虚构演示路线及模板 ZIP；下载不写 SQLite 或用户文件。
- `app/storage.py`：SQLite 档案、简历、版本、设置和备份。
- `app/parsers.py`：DOCX、PDF、图片、XLSX、文本、OCR 和模板风格解析。
- `app/providers.py`：多服务商配置、OpenAI 兼容协议与 Anthropic Messages 协议适配。
- `app/ai.py`：统一结构化输出、岗位匹配、OCR 校对、跨行业事实提取与类型路由、学习路径和课程语义复核、改写和动态追问。
- `app/learning.py`：本地课程目录、Brave/Tavily 实时检索、具体课程 URL 校验、去重与缓存衔接。
- `app/renderers.py`：同源 HTML/PDF 预览和 Word 文档生成。
- `web/`：中文分步界面、结构化编辑、折叠工具卡、模板切换和导出操作。

## 本地安全边界

- 服务只监听 `127.0.0.1`。
- 上传文件只在请求期间解析，不默认保存原文件。
- SQLite 和照片保存在项目下的 `data/`，该目录不进入版本控制。
- API Key 使用系统当前账户安全存储：Windows 使用 DPAPI，macOS 使用“钥匙串”；备份不包含 API Key。
- 发给云端 AI 的内容由用户主动触发，并在首次使用对应服务商时确认范围；结构化档案调用会排除姓名、联系方式、城市、链接和照片，文本导入中的手机号与邮箱会替换为占位符。本地 Ollama/LM Studio 不离开电脑。
- 本地 HTTP 服务校验 Host 与 Origin，并限制请求体大小，避免其他网页直接操作本地简历数据。
- 网页静态资源禁用缓存，避免升级后新 HTML 与旧 JS/CSS 混用。
- 历史版本最多保留 100 个；备份恢复会去重，恢复历史版本前会保存真实的当前状态。

## 第一版验收检查

1. 启动脚本能打开本地网页，健康检查返回成功。
2. DOCX、文本 PDF、扫描 PDF/图片均有明确解析结果或可操作错误信息。
3. 结构化档案可编辑、保存、刷新后恢复。
4. 粘贴 JD 后可得到匹配分析，未配置 Key 时给出明确引导。
5. 岗位定制内容保存在独立工作区；AI 修改可撤销和恢复，切换岗位后旧 AI 任务不得写入新岗位。
6. 动态追问一次显示一个问题，支持跳过和结束。
7. 三类内置模板可切换；Word/PDF/图片参考模板可重建为受约束的可编辑样式；支持模块排序、一页默认和多页选项。
8. PDF 一键导出可打开，页面尺寸为 A4，和预览共用渲染源；一页缩放低于 75% 时阻止导出并提示精简或多页。
9. Word 一键导出可打开、可编辑，内容顺序正确；界面明确说明不同 Word 字体环境可能产生轻微重排。
10. 历史版本可恢复且能撤回恢复操作；重复导入同一备份不会复制历史版本。
11. JD 截图校对保留原文、校对版和撤销入口；材料案例未确认前不进入补充信息；学习路径只在跨行业模式显示，外部搜索仅发送学习主题。
12. 七步引导可下载一套明确标注“演示专用”的完整资料包；下载前后应用状态保持一致，包内旧简历和模板可被现有解析链路读取。
