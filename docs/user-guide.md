# 简历工坊用户指南

## 1. 这是什么

简历工坊是一款运行在 Windows 或 macOS 本机、通过浏览器操作的 AI 简历工具。它把旧简历整理成可复用的基础人才档案，再根据不同岗位的 JD（Job Description，职位描述）生成彼此独立的岗位简历。

基础档案、岗位版本、历史记录和照片默认保存在本机。只有在你主动点击 AI 分析、生成或修改时，必要文本才会发送给所选模型服务；也可以使用本机 Ollama 或 LM Studio。

## 2. 启动与首次设置

### 启动

#### 使用安装包（推荐给体验用户）

- Windows 10/11 x64：运行 `ResumeWorkshop-Setup-Windows-x64.exe`，安装完成后从桌面或开始菜单打开“简历工坊”。
- macOS：Intel 芯片下载 `Intel-x64`，M 系列芯片下载 `Apple-Silicon-arm64`。当前安装包没有 Apple Developer ID 签名，第一次启动请在 Finder 中右键应用并选择“打开”，再确认一次。
- 应用启动后会自动打开本机浏览器。第一次进入先确认内容、隐私和许可边界，再出现七步新手引导；以后可点击页面右上角“？”重新打开。引导中的“前往此功能”不会自动填充或覆盖档案。

安装包已内置本地 OCR 和 PDF 导出所需的 Chromium，不需要朋友另外安装 Python、Node.js 或浏览器组件。Windows 用户数据位于 `%LOCALAPPDATA%\ResumeWorkshop`；macOS 用户数据位于 `~/Library/Application Support/ResumeWorkshop`。卸载或升级应用不会主动删除这些资料。

#### 从源码启动

双击项目目录中的 `start.bat`。也可以在 PowerShell 中进入项目目录后运行：

```powershell
python -m app.main
```

浏览器会自动打开 `http://127.0.0.1:8877`。如果没有自动打开，可以手动复制这个地址到浏览器。

### 配置 AI 模型

1. 点击页面右上角的齿轮按钮。
2. 选择 DeepSeek、OpenAI、Anthropic Claude、MiniMax、GLM、Kimi、MiMo、Ollama、LM Studio 或自定义 OpenAI 兼容接口。
3. 核对模型名和 API 地址；云端服务填写自己的 API Key，本地服务通常可以留空。
4. 点击“测试连接”，成功后再“保存设置”。

Key 会按服务商分别使用系统当前账户的安全存储保存在本机（Windows 使用 DPAPI，macOS 使用“钥匙串”），不会进入数据备份。首次使用某个云端服务时，页面会展示本次可能发送的数据范围并要求确认。没有可用模型连接时，资料手动编辑、预览和部分本地解析仍可使用，但岗位分析、AI 生成、AI 修改和翻译不能使用。

DeepSeek 已做真实接口验证；其他云端适配在缺少维护者真实 Key 时使用协议级模拟测试。服务商模型名和区域端点可能变化，请以“测试连接”的实际结果为准。

### 使用完整演示资料包

第一次使用建议先在新手引导左侧点击“下载完整演示资料包”。这是唯一的演示资料入口，ZIP 中的所有人物、公司、学校、联系方式和经历均为虚构内容，并明确标注“演示专用”；下载本身不会写入或替换当前档案。

解压后可以选择两条路线：

- `01-同行业跳槽-FDE`：把一份 AI 应用工程师旧简历定制为 FDE 简历，适合演示相关经历的筛选、重组和强化。
- `02-跨行业转行-FDE`：把一份桥涵设计工程师旧简历转为初级 FDE 简历，适合演示基础信息复用、跨行业模式、个人项目草稿和学习路径。

每条路线都包含旧简历、目标岗位 JD、补充经历和项目证据文件夹；跨行业路线还包含 JD 截图，可演示 OCR 与自动校对。`03-自定义简历模板` 中提供可导入的 Word 模板，`04-建议录屏顺序.txt` 给出从导入到导出的完整演示顺序。

推荐按七步引导完成：下载资料包、导入旧简历、确认档案、识别 JD、选择求职方式、编辑岗位正文、导入模板并导出。演示结束后，可以保存岗位版本，也可以新建岗位简历；基础档案只有在你主动导入、编辑和保存时才会变化。

## 3. 推荐使用流程

### 第一步：导入资料

可以使用以下任一种方式：

- 点击“选择文件（可多选）”，一次选择多份 DOCX、PDF、扫描件或图片。
- 把文件拖入上传区域。
- 把已有的简历文字粘贴到文本框。
- 不导入文件，直接进入下一步手动填写。

单个文件最大 20 MB。多文件会逐份解析，并按文件名合并提取结果。

扫描 PDF 和图片会优先使用本地 OCR。页面提示“识别可信度偏低”时，应重点检查姓名、电话、公司、时间、数字和专业术语。OCR 结果只是草稿，不会替代后续人工确认。

### 第二步：确认基础人才档案

系统会把导入内容拆成基本信息、工作经历、项目经历、教育背景、技能、证书和语言能力等模块。

逐项检查并修正：

- 姓名、电话、邮箱和城市是否正确。
- 公司、职位和任职时间是否被识别错位。
- 工作成果是否存在乱码、错误换行或漏字。
- 项目、教育和技能是否放在正确模块。
- 是否需要添加个人照片。

这里保存的是所有岗位共用的基础人才档案，应尽量只写真实发生的内容。后续岗位定制不会覆盖这份档案。

### 第三步：填写岗位 JD

在“目标岗位 JD”中：

- 直接粘贴岗位职责、任职要求和加分项；或
- 在文本框获得焦点后按 `Ctrl+V` 粘贴一张或多张岗位截图。

岗位截图会使用本地 OCR 提取文字。识别后先检查原文，再点击“开始匹配分析”。匹配分用于发现关键词、优势和信息缺口，不代表真实录用概率。

### 第四步：选择生成模式

#### 同方向跳槽

适合已有相关工作或项目经历的人。AI 会重组、筛选和改写现有经历，明显无关的内容可以不进入岗位简历。

#### 跨行业转行

适合基础档案与目标岗位相关性较低的人。AI 可以根据 JD 生成明确标注的个人项目、模拟项目或案例研究，以及相应技能草稿，但不会新增虚构公司或任职时间。

能力层级控制项目复杂度和表达深度：

- 小白：基础概念和小型练习。
- 入门：常用工具和基础个人项目。
- 熟练：端到端个人或模拟项目，包含验证与迭代。
- 精通：复杂方案、权衡和方法论，但仍不虚构公司履历或精确业绩。

“补充信息”可以填写与岗位相关、但旧简历中没有的兴趣、学习、练习或工具经历。留空也可以生成。

#### 从材料文件夹整理通用案例

展开“从项目文件夹整理案例”，选择代码项目或工作资料文件夹。新版 Edge/Chrome 会直接授予本地目录读取权限；旧浏览器如果出现“上传”按钮，它也只代表把文件清单交给当前本地网页，不会把文件夹保存到云端。系统会先在最多 300 个候选文件中筛选，再优先读取说明文档、架构或设计材料、核心内容和测试，最终最多分析 40 个文件、约 12 万字；`.git`、`.dart_tool`、依赖、构建目录、缓存、密钥和大文件会被跳过。

支持 DOCX、PDF、图片、XLSX、CSV、Markdown 和常见代码文本。系统会分批提取带文件名与原文摘录的事实，再自动识别软件、工程、金融、研究、商业、文章、管理、教学或通用案例。草稿下方可以展开查看逐条材料依据；识别类型不合适时，选择正确类型并点击“按此类型重新整理”。只有点击“加入补充信息”后，草稿才会参与岗位简历生成。

#### 转行学习路径

跨行业模式下，先完成岗位匹配，再展开“转行学习路径”。系统会把岗位缺口拆成有前置关系的具体知识、规范、软件和实操任务，并给出阶段目标、资源类型、交付物和完成标准。

默认只使用本地已核验课程目录。若要覆盖市政桥涵设计等任意职业，在“设置与数据”中选择 Brave Search 或 Tavily 并填写对应 API Key。系统只向搜索服务发送学习主题，不发送姓名、电话、完整简历或完整 JD；检索结果必须是具体课程或视频页面，再由当前 AI 模型根据阶段目标审核相关性。搜索结果在本地缓存 30 天。没有通过审核的课程时会明确提示“暂未找到”，不会用搜索页代替课程。每个学习阶段可以点击“换一批课程”；每个课程卡片下方既可标记“有用、不相关、太难、太简单、链接失效”，也可填写自己的评价。反馈保存在本地，后续会排除不相关和失效资源，并随数据备份导出。

### 第五步：编辑岗位定制正文

生成完成后，“岗位定制简历正文”就是后续预览和导出的内容。

你可以：

- 直接修改任何输入框。
- 手动新增或删除工作、项目、技能、教育等模块。
- 点击某个字段，让右侧 AI 只修改该字段。
- 在字段中选中一段文字，让 AI 精准改写选中内容。
- 不选择字段，让 AI 智能新增、删除或重新生成整份简历中的模块。
- 使用“撤销上次操作”和“恢复上次操作”在 AI 修改前后切换。

如果 AI 重复废话，可以明确说明删除哪些内容、保留哪些事实、需要新增什么项目，以及期望的字数和语气。

示例：

> 删除第二个模拟项目。新增一个“通达信 RPS 指标工具”个人项目，包含个股 RPS 三线红、板块 RPS 三线红和月线反转，用 3 条成果描述，避免空泛措辞。

### 可选：动态追问

展开“需要时再用：动态追问”，系统会结合当前岗位正文和 JD，一次提出一个高价值问题。

- 可以提交答案并继续下一问。
- 可以跳过没有价值的问题。
- 可以结束本轮追问。
- 可以用“上一问”和“下一问”查看或修改以前的答案。

提交后应查看页面提示的实际改动位置；如果结果不满意，可以直接编辑或撤销。

### 第六步：排版与导出

可以选择：

- 模板：ATS 稳定、编辑部、轻创意，或导入 Word、PDF、图片作为自定义模板参考。
- 语言：中文、英文、中英混排。
- 页数：默认一页或允许多页。
- 模块顺序：调整各模块的展示次序。

默认一页会自动压缩内容。当缩放低于 75% 时，字号可能过小，系统会阻止 PDF 导出并提示精简内容或改为多页。

自定义模板会提取主色、单双栏倾向、标题对齐、字体和照片倾向，再重建为可编辑版式。它追求风格接近和稳定导出，不保证与原模板像素级一致，也不会导入模板中的示例人物与文字。页面每次展示 3 个主打免登录使用的模板网站入口，可以点击“换一批”轮换；当前包括 YY简历网、简历下载网、Career Reload 等。第三方规则可能变化，下载时仍应核对是否免费、是否需要登录以及下载按钮是否为站点原生入口。

导出方式：

- “一键导出 PDF”：与右侧 A4 预览使用同一渲染源。
- “一键导出 Word”：生成可继续编辑的 DOCX；不同电脑的字体环境可能造成轻微重排。
- “使用 Ctrl+P 备用打印”：PDF 一键导出异常时的备用方式。

导出前建议完成“投递前检查”，并人工核对姓名、联系方式、目标职位、时间、数字和项目真实性。

## 4. 管理不同岗位简历

页面顶部提供三项操作：

- “保存当前岗位”：把当前 JD、岗位正文、排版和问答保存到岗位库。
- “新建岗位简历”：清空当前岗位内容并开始新岗位，基础人才档案保持不变。
- “岗位库”：打开或删除以前保存的岗位版本。

开始新岗位前，应先保存当前岗位。打开其他岗位会替换当前工作区的岗位内容，但不会修改基础人才档案。

## 5. 历史版本、备份与恢复

系统会保存重要操作的历史版本，最多保留 100 个。在设置中可以恢复历史版本；恢复前系统会保留真实的当前状态，因此还可以撤回恢复操作。

建议定期点击“下载备份”，尤其是在：

- 大量修改基础档案前。
- 导入新的真实简历前。
- 升级程序或更换电脑前。
- 已完成一份重要岗位简历后。

恢复备份会替换当前档案和岗位数据，系统会先创建快照。备份不包含任何 AI 或搜索 API Key。

## 6. 关于、更新与支持作者

点击右上角“i”可查看版本、许可摘要、联系邮箱和支持作者入口。微信/支付宝支持完全自愿，不会解锁功能或改变技术支持。第一次成功导出后会显示一次提醒；关闭后不再自动弹出。

“检查新版本”只在点击时访问 GitHub Releases，不会发送简历、档案或使用数据。本项目不包含后台自动更新、遥测或崩溃上报。

当前安装包没有付费代码签名。请只从 `https://github.com/wu-hongliii/resume-workshop/releases` 下载，并核对同名 `.sha256` 文件。

## 7. 常见问题

### 点击“选择文件”没有弹出窗口

刷新页面后重试，并确认使用的是 `http://127.0.0.1:8877`。也可以把文件直接拖进上传区域。

### OCR 错字较多

优先使用清晰、正向、无压缩的原图；扫描 PDF 尽量保证每页分辨率足够。JD 多图会逐张 OCR，再由 AI 自动修正明显错字。可以查看原始识别、修改明细，并撤销自动校对；最终仍应人工检查岗位名、技术词、数字、日期和薪资。

### 更新后按钮显示但无法点击

重新启动本地服务并刷新页面。当前版本已禁止缓存网页 CSS/JavaScript，正常情况下不再需要强制刷新；如果旧标签页仍开着，关闭后重新访问 `http://127.0.0.1:8877`。

### AI 提示没有返回可解析 JSON

先在设置中点击“测试连接”。仍失败时，检查 API Key、模型名、API 地址、网络和服务状态；也可以缩短过长的 JD 或补充内容。

### 岗位正文与 JD 不一致

如果修改过 JD，重新生成岗位定制简历。页面出现“JD 已发生变化”时，不要继续导出旧正文。

### 一页放不下

删除重复内容、缩短不重要的 bullet、减少无关模块，或切换为“允许多页”。不要通过过小字号强行塞进一页。

### PDF 导出失败

先使用页面的 `Ctrl+P` 备用打印。如果提示缺少 Chromium，在项目目录运行：

```powershell
python -m playwright install chromium
```

## 7. 使用边界

AI 生成内容是可编辑草稿。跨行业模式允许生成个人项目和模拟项目，但最终投递内容仍应由用户判断、修改并承担责任。不要把模拟项目伪装成公司任职经历，也不要保留自己无法解释、演示或回答追问的内容。
